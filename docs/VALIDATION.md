# v0.3 界面验证记录

2026-10-15，在本目录隔离的真实 DSH Web `0.2.0-rc.2` 实例完成以下检查。收尾执行 `pnpm run check`，构建成功且 24 项自动测试全部通过；下表与截图记录 v0.3 的实际界面和交互结果。

| 检查 | 结果 |
| --- | --- |
| 1280×840 浅色、深色 | 内置叮东 PNG 成功解码，尺寸为 1247×1261；透明背景无白底，角色叠加在图书馆草坪画面上 |
| 四牌楼深色欢迎卡 | 切换到四牌楼后，大礼堂照片与内置叮东正常显示 |
| 叮东显示开关 | 关闭后欢迎卡中叮东图片数为 0，开启后为 1 |
| 替换与恢复内置形象 | 成功选择本地旧参考图；点击「恢复内置形象」后回到固定内置 PNG，显示开关保持开启；刷新后内置形象仍显示 |
| 设置入口与排序 | 侧栏全局面板仅显示「插件」，没有独立校园主题入口；宿主设置导航依次为通用、模型、内置插件、Agent 预设、校园主题(SEU) |
| 集中来源 | 欢迎卡逐图署名节点数为 0；「素材与署名」折叠块包含两张照片的作者、原作品页和许可，以及校徽、校训、配色、叮东参考来源与 AI 重建说明 |
| 390×844 窄窗口 | 无页面横向溢出，欢迎卡正常显示，输入区底部约 708.3px |
| 390×480 窄矮窗口 | 无页面横向溢出，欢迎卡顶部约 80.25px、输入区底部约 407.75px，均在可见区域内 |
| 窄窗口设置卡片 | 仅在校园主题设置卡片激活且窗口宽度不超过 600px 时，将宿主设置导航调整到顶部换行；内容区宽度与滚动宽度均为 321px，叮东开关和替换按钮可见且可操作 |
| 浏览器控制台 | 本轮最终检查的 error 日志为空 |
